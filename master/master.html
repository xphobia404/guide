MASTER DATA MODULE

Master Data User Guide

The Master Data module manages the reference data used throughout the Finance Management System, including vendors, entities, bank details, currencies, budget accounts, taxes, and operational references.

Reference Data Maintain consistent reference values across finance transactions.
Transaction Accuracy Ensure correct vendor, bank, entity, currency, and tax selection.
Access Control Master Data updates should be limited to authorized users.
Data Consistency Keep active records accurate to prevent errors in downstream workflows.
01

Vendors

The Vendors menu is used to manage suppliers, service providers, contractors, and other payees used in Purchase Orders, invoices, and payment transactions.

Typical vendor information

  • Vendor code and vendor name.
  • Address, email, phone number, and contact person.
  • Tax identification information where applicable.
  • Vendor status, such as Active or Inactive.
  • Related bank account information for payment purposes.

How to add a vendor

  1. Open Master Data → Vendors.
  2. Click Add Vendor or Create.
  3. Enter the vendor name, code, address, and contact details.
  4. Enter tax information and bank information when required.
  5. Set the vendor status to active if the vendor can be used in new transactions.
  6. Click Save.

Principals

The Principals menu manages principal or main business-party information used as a reference in operational and financial transactions.

How to manage principals

  1. Open Master Data → Principals.
  2. Click Add to create a new principal record.
  3. Enter the principal name, code, contact information, and related details.
  4. Set the record status based on whether it may be used in new transactions.
  5. Save the record and verify it appears in the principal list.

Vessels

The Vessels menu manages vessel records used to classify operational expenses, Purchase Orders, Cash Advances, and other vessel-related transactions.

How to add a vessel

Bank Accounts

The Bank Accounts menu manages company, vendor, employee, or other beneficiary bank account details used in payment transactions.

Typical bank account information

  • Account holder name.
  • Bank name and bank branch.
  • Bank account number.
  • Currency of the bank account.
  • Related vendor, entity, employee, or beneficiary.
  • Account status and verification status where applicable.

How to add a bank account

  1. Open Master Data → Bank Accounts.
  2. Click Add Bank Account.
  3. Select the related owner, such as a vendor or entity.
  4. Select the bank and enter the account holder name and account number.
  5. Select the applicable currency.
  6. Review the data carefully and save the record.

Taxes

The Taxes menu manages tax references used to calculate and classify taxes in Purchase Orders, invoices, payment requests, and reports.

Typical tax information

  • Tax name and tax code.
  • Tax rate or percentage.
  • Tax type, such as input, output, withholding, or other tax categories.
  • Effective date or status.
  • Related accounting or budget reference if available.

How to add a tax record

  1. Open Master Data → Taxes.
  2. Click Add Tax.
  3. Enter the tax code, tax name, and tax rate.
  4. Select the tax type or applicable category.
  5. Set the tax record status and save it.

Common Master Data Actions

Most Master Data menus provide similar actions for creating, reviewing, editing, activating, and deactivating reference records.

Add Create a new reference record that can be used in future transactions.
View Detail Review complete record details, related information, and current status.
Edit Update an existing record when information changes or needs correction.
Activate / Deactivate Control whether a record can be selected in new transactions.
Search and Filter Find specific records using a name, code, category, status, or related reference.
Export Download data for review, reconciliation, migration, or audit if the feature is enabled.
i

When a record has already been used in financial transactions, it is generally safer to deactivate it rather than delete it. This preserves historical transaction integrity.

✓

Master Data Governance

Follow these guidelines to maintain clean, accurate, and secure reference data across the Finance Management System.

1
Verify Before Saving Check names, codes, values, and required references before creating records.
2
Avoid Duplicates Search existing records before adding new vendors, accounts, entities, or codes.
3
Use Status Control Deactivate obsolete records instead of deleting records used in transactions.
4
Protect Sensitive Data Restrict access to bank accounts, tax data, and financial references to authorized users.
✓

Accurate Master Data improves transaction quality, reduces payment errors, supports reliable reports, and makes approval and audit processes easier to manage.
