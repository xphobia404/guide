USER MANAGEMENT MODULE

User Management Guide

The User Management module is used to manage user accounts, assign roles, control account status, reset credentials, and maintain secure access to the Finance Management System.

User Accounts Create and maintain accounts for authorized Finance Management System users.
Role Assignment Assign roles to determine the menus and actions each user can access.
Status Control Activate, deactivate, or lock accounts based on current access requirements.
Credential Security Reset passwords and maintain secure access administration practices.
01

User Management Overview

User Management is typically restricted to administrators or authorized system administrators responsible for account access.

Typical user information

  • Full name and employee or user identifier.
  • Email address and username.
  • Assigned role or roles.
  • Entity, department, or vessel access where applicable.
  • Account status and last activity information if available.

Recommended management flow

1
Create Account Add the user’s identity and login information.
2
Assign Role Assign the appropriate role and access scope.
3
Activate User Enable the account after access has been reviewed.
4
Review Access Review roles and account status periodically.
i

User access should follow the principle of least privilege. Give each user only the permissions required to perform their assigned work.

02

User List

The User List displays all registered user accounts that are visible based on the administrator’s access level.

Common actions from the User List

  • Search users by name, username, email, role, or status.
  • Open user details to review profile and assigned access.
  • Create a new user account.
  • Edit existing user information.
  • Activate, deactivate, or lock a user account.
  • Reset a user password when authorized.

How to find a user

  1. Open the User menu.
  2. Use the search field to enter a name, username, or email address.
  3. Use filters such as role, department, entity, or account status when available.
  4. Select a user row to view the user detail page.

03

Create User

Create a new user account when a new employee, administrator, or authorized business user needs access to the system.

How to create a user

  1. Open the User menu.
  2. Click Add User, Create, or the equivalent action.
  3. Enter the user’s full name.
  4. Enter a unique username and valid email address.
  5. Enter or generate an initial password if the system requires it.
  6. Select the appropriate role or roles.
  7. Assign entity, department, vessel, or other access scopes if available.
  8. Set the account status to Active only after confirming the access configuration.
  9. Click Save.

!

Do not reuse usernames or share accounts between users. Each person should have an individual account so that actions can be traced through the system audit trail.

04

Edit User

Use the Edit User function to update user identity data, contact information, access scope, or role assignment when business needs change.

When to edit a user

  • The user changes department, entity, vessel, or job responsibility.
  • The user’s name or email address needs correction.
  • The user requires an updated role or access scope.
  • The user should no longer access a specific finance module.

How to edit a user

  1. Open the User menu.
  2. Search for and select the user account.
  3. Click Edit.
  4. Update the required profile, access scope, or role information.
  5. Review the user’s account status.
  6. Click Save Changes.

05

Assign Role

Roles control which modules, pages, records, and actions a user may access in the Finance Management System.

Examples of role-based access

Operational User May create and submit Purchase Orders, Cash Advances, Allowances, Payroll, or Liquidation records.
Controller User May review documents, validate transactions, confirm invoices, and approve or return records.
Treasury User May process payment requests, review payment details, and release approved payments.
Approver May approve, return, or reject transactions based on the assigned approval authority.
Master Data Admin May manage reference data such as vendors, banks, currencies, taxes, and budget accounts.
System Administrator May manage users, roles, permissions, and other system administration settings.

How to assign a role

  1. Open the User menu.
  2. Select the user account you want to update.
  3. Click Edit.
  4. Find the Role or Assigned Roles field.
  5. Select the required role or roles.
  6. Set related entity, department, vessel, or approval scope if available.
  7. Save the changes.
  8. Ask the user to sign out and sign in again if the system requires a new login session to apply permissions.
!

Avoid assigning administrator-level roles unless the user is explicitly authorized. High-level roles can provide access to sensitive financial, user, role, and payment data.

06

Account Status

Account status controls whether a user can log in and use the Finance Management System.

How to change account status

  1. Open the User menu.
  2. Search for and select the target user.
  3. Click Edit or use the account status action in the user list.
  4. Change the status according to the user’s current access requirement.
  5. Save the change and verify the updated status.

07

Reset Password

Reset a password when a user forgets their password, cannot access their account, or when a credential reset is required for security reasons.

How to reset a password

  1. Open the User menu.
  2. Search for and select the target user account.
  3. Use Reset Password, Change Password, or the equivalent action.
  4. Enter a temporary password or trigger a password reset process if supported.
  5. Save or confirm the reset action.
  6. Provide the new temporary credential using a secure communication channel.
  7. Ask the user to change the password immediately after their next login if supported.

User Status Reference

Status labels may vary depending on the system configuration, but the following are common account states.

Status Description Administrator Action
Active The user can log in and access the modules allowed by their assigned role. Review access periodically and update roles when responsibilities change.
Inactive The user account is retained but cannot access the system. Use this status for users who no longer need access while preserving audit history.
Locked The account is temporarily blocked, often because of a security event or repeated failed logins. Verify the user identity and reset credentials or unlock the account according to policy.
Pending The account has been created but is not yet fully activated or configured. Complete role assignment, access scope, and activation review before enabling access.
✓

User Management Security Guidelines

Follow these practices to protect financial data, payment workflows, and system access.

1
Use Individual Accounts Each user must have a unique account. Shared accounts should not be used.
2
Assign Minimum Access Grant only the roles and permissions required for the user’s job.
3
Review Access Regularly Review user roles after transfers, resignations, role changes, or policy updates.
4
Deactivate Promptly Deactivate access as soon as a user no longer requires system access.
✓

Proper user administration improves accountability, reduces unauthorized access risk, and ensures that approval and payment activities remain traceable to the responsible user.
