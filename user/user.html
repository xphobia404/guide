USER MANAGEMENT MODULE

User Management Guide

The User Management module is used to manage user accounts, assign roles, control account status, reset credentials, and maintain secure access to the Finance Management System.

User AccountsCreate and maintain accounts for authorized system users.
Role AssignmentAssign roles that determine accessible menus and actions.
Status ControlManage account availability according to access requirements.
Credential SecurityReset passwords and maintain secure account access.
01

User Management Overview

Use the User menu to review registered accounts and manage their access.

User List Overview

The User List shows existing accounts along with user information, assigned roles, and available actions.

02

User List and Filter

Use searching and filters to locate accounts quickly before viewing or changing them.

How to filter users

  1. Open the User menu.
  2. Use the filter action to open available filter fields.
  3. Select the required criteria, such as role or account status.
  4. Apply the filter and review the matching user records.

03

Create User

Create a new user account when an authorized employee or administrator requires system access.

How to create a user

  1. Open the User menu and select the create-user action.
  2. Enter the user identity and contact information.
  3. Select the appropriate role and configure access as required.
  4. Review the information and save the new account.
Screenshot — Start creating a useruser-create.png
Screenshot — Create user formuser-create-1.png
Screenshot — Complete create user detailsuser-create-2.png
!

Do not reuse usernames or share accounts. Individual accounts preserve accountability in audit records.

04

Edit User

Update a user’s profile, role, access scope, or account settings when business responsibilities change.

How to edit a user

  1. Find the user from the User List.
  2. Open the available action menu and select Edit.
  3. Change the required profile, role, or access information.
  4. Save the changes after reviewing the account configuration.

05

Reset Password

Reset credentials when a user cannot access their account or a reset is required for security reasons.

How to reset a password

  1. Find the target account in the User menu.
  2. Open the available actions and choose the password reset option.
  3. Enter or confirm the temporary password or reset process.
  4. Save the change and provide credentials through an approved secure channel.
Screenshot — Reset password actionuser-reset.png
Screenshot — Reset password dialoguser-reset-1.png
!

Never send permanent passwords through public chat channels. Use a temporary password, secure reset link, or approved internal process.

User Status Reference

These common account states control whether users may access the system.

StatusDescriptionAdministrator Action
ActiveThe user can log in with access defined by assigned roles.Review access periodically.
InactiveThe account is retained but cannot access the system.Use when access is no longer required while preserving history.
LockedThe account is temporarily blocked after a security event or failed logins.Verify identity before unlocking or resetting credentials.
PendingThe account exists but is not fully configured or activated.Complete role and access review before activation.

User Management Security Guidelines

Use these practices to protect financial data and workflow access.

1
Use Individual AccountsEach user must have a unique account.
2
Assign Minimum AccessGrant only necessary roles and permissions.
3
Review Access RegularlyReview roles after transfers or role changes.
4
Deactivate PromptlyRemove access when it is no longer needed.
✓

Proper user administration improves accountability and keeps approval and payment actions traceable to responsible users.
